# Lab12-SWNT

Repositorio del laboratorio de Innovación Software apoyada en Nuevas Tecnologías.

## Proyecto integrador 3: El Núcleo UI (React + IA)

El proyecto **EcoTrack – Dashboard de Emisiones en Tiempo Real** se encuentra en la carpeta [`ecotrack-emissions/`](./ecotrack-emissions/).

Incluye:
- React + TypeScript con Vite.
- Componentes `EmissionsTracker`, `EmissionCard` y `EmissionForm`.
- Hook personalizado `useEmissions`.
- Integración con Supabase y ejemplo de esquema SQL.
- Tailwind CSS y datos de demostración.

Consulta [`ecotrack-emissions/README.md`](./ecotrack-emissions/README.md) para las instrucciones de instalación y ejecución.
